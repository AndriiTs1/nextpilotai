# NextPilotAI

NextPilotAI is a modern Full-Stack development studio focused on building high-performance web applications, AI-powered solutions, and business automation platforms.

Built with modern technologies and best practices, the project serves as both a company website and a showcase of engineering quality.

---

## 🚀 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint
- Vercel

---

## 📦 Getting Started

Clone the repository:

```bash
git clone https://github.com/AndriiTs1/nextpilotai.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```

---

## 🛠 Available Scripts

```bash
npm run dev
```

Runs the development server.

```bash
npm run build
```

Builds the application for production.

```bash
npm run start
```

Starts the production server.

```bash
npm run lint
```

Runs ESLint.
