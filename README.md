# NextPilotAI

NextPilotAI is a modern Full-Stack development studio focused on designing and building custom digital solutions for small and medium-sized businesses.

The project showcases an engineering-first approach where every solution starts with understanding the business process, designing the system architecture, and only then implementing the technology.

This repository contains the source code for the official NextPilotAI website.

---

# Features

- Modern responsive website
- Business-oriented service presentation
- AI-ready architecture
- Local SEO optimization
- Structured data (JSON-LD)
- Optimized performance
- Accessibility-focused UI
- Dark premium design system

# Getting Started

Clone the repository:

```bash
git clone https://github.com/AndriiTs1/nextpilotai.git
```

Move into the project:

```bash
cd nextpilotai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# Available Scripts

### Development

```bash
npm run dev
```

Starts the local development server.

### Production Build

```bash
npm run build
```

Builds the application for production.

### Production Server

```bash
npm run start
```

Runs the production build locally.

### Lint

```bash
npm run lint
```

Runs ESLint checks.
